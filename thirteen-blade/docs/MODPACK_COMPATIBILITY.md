# 整合包适配记录

验证日期：2026-09-23。新增 Forge 两版保持玩法版本 0.4.1，使用各自游戏版本的原生接口。客户端与服务器必须安装相同游戏版本、加载器版本的本模组；四份 JAR 不可混装。

| 目标 | 游戏 / Java | 已核对的加载器 | 安装文件 |
| --- | --- | --- | --- |
| RLCraft 2.9.3 | 1.12.2 / Java 8 | Forge 14.23.5.2860 | `thirteen-blade-forge-1.12.2-0.4.1.jar` |
| Better MC BMC4 Forge | 1.20.1 / Java 17 | Forge 47.4.20 | `thirteen-blade-forge-1.20.1-0.4.1.jar` |

上表加载器版本来自用户本机游戏实例的版本文件。Better MC 只确认了 BMC4 / Forge 1.20.1 和该实例的实际文件，未据此推断整合包的具体发布编号。

## RLCraft

- Forge 1.12.2 独立构建的 16 项单元测试通过，涉及成长边界、数值校验、Java 8 本机模拟 API、错误返回、响应限制、超时和私人对话内容。
- 真实独立服务器验证 11 组场景，覆盖主副手成长 / 回血、10 级封顶、12 类生物吞噬及末影龙飞行、24 点韧性、升级 NBT、药水优先级、黄心、防火掉落物存档、强化怪物、无效击杀、效果保存 / 到期和无限待命。
- 正式混淆 JAR 在 Forge 14.23.5.2860 + First Aid 1.6.22 下通过 12 组场景；读取实例里的 First Aid 配置，验证所有部位升级回满、普通击杀不治疗、携带高等级剑按 First Aid 规则扩大部位上限。
- 复制完整 RLCraft 模组和配置到工作区，服务端成功加载并进入新建测试世界，日志记录加载 163 个模组，12 组场景通过。该计数包含 Forge 的内部模组和独立测试模组，不等于客户端 JAR 个数。
- First Aid 测试使用无真实客户端连接的服务端玩家，First Aid 的发包路径会记录测试连接缺失警告；身体部位和服务器属性断言通过。此验证不等于真实多人网络同步试玩。

1.12.2 配方使用下界之星、钻石剑、末影珍珠。没有幻翼 / 掠夺者 / 监守者 / 旋风人，不开放对应新版固有刻印。其他模组怪物可提供敌对物种韧性及持续正面药水效果。第一人称战斗表现和 RLCombat 的操作手感仍需实际客户端体验。

First Aid 的部位上限、Scaling Health 的属性调整等整合包规则仍有效，不为剑强行移除它们。没有修改原整合包的配置、mods 或存档。

## Better MC

- 使用实例的 Forge 47.4.20 构建；16 项单元测试、17 项真实 GameTest 通过。
- GameTest 覆盖本版本存在的固有能力、末影龙、主副手、背包生命、回血边界、升级 NBT 与附魔、吞噬冷却、外部药水、黄心、自然强化与存档。
- 完整客户端模组和配置已复制到隔离服务端进行启动验证。客户端专用渲染 / 音频模组不能直接用于独立服务器；测试副本排除了 Audio Improvements、BadOptimizations、CIT Resewn、Colorwheel、Continuity、Entity Model Features、Entity Texture Features、Oculus、Particle Effects、Particle Core、Stop Rendering。未修改用户原实例。
- 最终测试：实例原有 368 个 JAR，测试副本排除上述 11 个客户端专用模组后加入十三契刃，Forge 47.4.20 成功加载、进入新世界，并通过控制台正常停止、保存全部维度，退出码 0。这是专用服务端启动验证；未进行完整 Better MC 客户端试玩。

本模组本身不依赖 Fabric API / Connector，但保留整合包已有的桥接依赖。1.20.1 没有旋风人，其余 15 类固有刻印可获取。
