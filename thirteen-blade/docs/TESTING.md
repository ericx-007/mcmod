# 验证记录与试玩清单

验证环境：Windows、JDK 17.0.19、Minecraft 1.20.1、Fabric Loader 0.16.14、Fabric API 0.92.2+1.20.1。

## 自动验证

```powershell
.\gradlew.bat --gradle-user-home .gradle-user-home build
.\gradlew.bat --gradle-user-home .gradle-user-home runGametest
python tools\validate_resources.py
```

`build` 包含 JUnit 测试；`runGametest` 在 Minecraft 自带测试世界内运行服务器测试，不需要打开客户端；测试模组不打包进发布 JAR。资源检查脚本额外需要 Python 和 Pillow。

JUnit（16 项）覆盖：

- 12 / 13 / 26 次击杀边界，143 次达到 11 级，1300 次达到 100 级；旧配置 `maxLevel` 无法恢复旧上限。
- 负击杀数据、整数溢出、非法配置、改配置后重新计算等级。
- 对本机模拟 HTTP 服务发出真实请求，验证 Unicode 回应、请求字段、密钥位置、最近 20 条历史。
- HTTPS / 本机 HTTP 地址校验，异常状态码，异常 / 空响应，超大响应，响应正文停滞时的总超时。
- 屏蔽 Minecraft 格式控制符，首次启动默认离线并生成配置。
- 强化怪物概率、效果数量 / 等级、无限与有限时长设置的边界。

Minecraft GameTest（23 项）覆盖：

- 剑承受 1000 次耐久扣除仍不损坏；击杀数、能力和身份经 NBT 序列化 / 反序列化保留。
- 通过实际 `PlayerEntity.attack` 击杀，第 13 次升级；生命上限增加但不回血，多次刷新不叠加；剑完全离开物品栏后，下一次攻击立即移除加成并截断超额生命。
- 射箭、幼年生物不计数，村民及已驯服狼被排除。
- 开启吸收后下一次僵尸击杀解锁饥饿免疫，之后的骷髅击杀不会重复使用吸收机会，冷却保留。
- 真实 Mixin 阻止持剑时施加饥饿效果，收剑后正常施加。
- 强制概率 100% / 0% 的自然生成流程，排除刷怪笼 / 刷怪蛋 / 命令、Boss、幼年怪物；强化属性保存重载不重复叠加。
- 亡灵强化怪物的效果池排除其免疫的生命恢复，确保仍得到有效增益。
- 蜘蛛 / 洞穴蜘蛛与苦力怕的固有能力，无限状态和初始 4 点黄心。
- 技能击杀同时夺取全部持续增益和物种刻印，不夺取负面 / 瞬间效果；未开启技能不夺取。
- 药水等级封顶与去重、NBT 保存恢复，有限时长边界及撤销。
- 黄心受到实际伤害后消耗，反复刷新、切换主手和清除效果均不补满；吸收奖励可以补满。
- 外部普通药水优先且收剑后保留，剑效果的归属标记可保存恢复。

- 副手真实近战击杀、开启吸收、夜视和饥饿免疫；同一把剑在主副手之间交换保留准备状态。
- 背包内剑仅提供生命，多把剑取最高，主手优先计杀；100 级实际生命为 220 点。
- 收剑 50 刻后余效仍在、101 刻后结束；收进背包仍保留生命。余效期间黄心受伤、重新持剑、另一把剑接管和普通药水覆盖均不串改归属。
- 不延长不足 5 秒的有限增益。

资源检查覆盖：62 个中英文翻译键及占位符、资源 JSON、32×32 RGBA 贴图透明通道、发布 JAR 中的客户端类 / 配方 / 模型 / Mixin refmap，以及测试类没有混入发布包。

报告：`build/reports/tests/test/index.html`、`build/gametest-results.xml`。这些检查不等同于完整客户端和多人联机试玩。

## 游戏内人工验收（尚未执行）

1. 进入创造模式世界，取剑，确认背包和第一 / 第三人称贴图正常；HUD 不遮挡关键界面。检查中文及英文、不同 GUI 缩放和按键重绑。
2. 工作台合成一把剑，确认结果正常，并确认钻石剑原附魔不会继承。
3. 用 `/give @s thirteenblade:thirteen_blade{ThirteenBlade:{Kills:12}}` 取得临界成长剑，分别主手、副手持剑击杀一个成年生物，检查升级提示、伤害和心数。
4. 分别对僵尸、骷髅、蜘蛛和苦力怕使用 V，检查四种能力共存；等待冷却后再次使用、重复吸收、吸收不支持生物、取消、切换主手、死亡和重进世界。
5. 已解锁夜视或缓降时放下剑，确认剑提供的效果约 5 秒后撤销；喝同名药水后再切换，确认外部药水效果保留。
6. 两把不同等级的剑交替使用、放入副手、存入箱子、交给第二名玩家、退出重进；确认成长跟随物品，放进背包仍加生命、存入箱子则取消，多把剑只取最高加成。
7. 主手或副手持剑时用 J 打开窗口发送离线消息，尝试长句、滚动、调整窗口大小；发送后关闭再打开；确认不会进入多人聊天。
8. 按 README 配置自己的服务，验证真实 API 成功回应、错误密钥、服务不可用和超时提示。尚未使用真实服务商密钥调用外部模型。
9. 在客户端和独立服务器均安装模组，修改服务器数值配置后重启，确认两名玩家的成长及能力互不干扰，客户端提示使用服务器数值。
10. 夜间寻找带发光轮廓的强化怪物；可临时把 `eliteSpawnChance` 设为 1 并重启测试。已有实体不会重新判定，命令召唤和刷怪蛋也不会走自然强化。
11. 测试药水抢夺无需等待随机刷怪，可用以下命令生成带速度 II、力量 I 的普通僵尸，再主手持剑按 V 击杀。命令怪本身不参与自然强化，但其增益可被抢夺：

```mcfunction
/summon minecraft:zombie ~ ~ ~ {NoAI:1b,PersistenceRequired:1b,ActiveEffects:[{Id:1b,Amplifier:1b,Duration:-1},{Id:5b,Amplifier:0b,Duration:-1}]}
```

12. 消耗黄心后，测试收剑、喝奶、交接武器和重进世界；确认只保留剩余黄心，再次技能击杀苦力怕才能补满。真实客户端 HUD 外观及多人联机手感仍需人工试玩。
