# 更新记录

## 0.4.0

- 基础十三契刃配方改用下界合金剑；成长封顶 10 级（默认 +20 攻击、+20 最大生命），封顶后继续记录击杀。
- 新增龙契·十三刃：基础剑与龙蛋无序合成，继承所有自定义数据，基础攻击 12，解除模组成长等级上限。
- 新增原创龙翼 / 黑曜石风格 64×64 进阶剑透明贴图。
- V 改为无限期准备、下一次有效近战击杀触发，触发后才开始 60 秒冷却；主动取消不扣冷却。
- 扩展为 16 类固有吞噬能力；旧蜘蛛缓降刻印改为隐身；末影龙提供创造式飞行。
- 首次吞噬敌对物种 +2 盔甲韧性，同族变种不重复累计；韧性属性数值上限放宽至 1024。
- 保留主副手生效、物品栏最高生命加成、药水五秒余效、随机强化、黄心保存和私有 API 对话；飞行也有五秒余效。
- 新增独立 Minecraft 1.21.1 / NeoForge / Java 21 版本，支持旋风人、沼骸和数据组件存储。
- Fabric：16 项 JUnit、31 项 GameTest；NeoForge：16 项 JUnit、14 项 GameTest。双版本发布资源验证通过。客户端画面、多人联机和真实服务商 API 仍需人工试玩。

升级说明：Fabric 0.3 的剑数据继续保留，原有高等级基础剑按新上限生效，与龙蛋合成后恢复全部击杀对应的等级。旧配置的吸收准备时长字段不再使用。两种加载器的 JAR 不可混装，也不是跨版本世界存档转换工具。
