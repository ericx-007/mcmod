# Minecraft Mods

- [十三契刃 / Thirteen Blade](thirteen-blade/README.md)：Minecraft 1.20.1 的 Fabric 成长剑模组，支持副手能力、物品栏生命加成、灵魂吸收和随机强化怪物。

构建、玩法、文件树及开发入门说明见项目目录。
